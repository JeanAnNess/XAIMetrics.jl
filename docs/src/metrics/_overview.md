# Metrics

`XAIMetrics.jl` organizes metrics into six categories:

- [Axiomatic](axiomatic.md)
- [Complexity](complexity.md)
- [Faithfulness](faithfulness.md)
- [Localisation](localisation.md)
- [Randomisation](randomisation.md)
- [Robustness](robustness.md)

Currently implemented metric types are documented under [Robustness](robustness.md).
